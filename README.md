# Plataforma Prado Verde - Monorepo

Sistema de Gestión Inteligente y Segura para Conjuntos Residenciales (Plataforma Prado Verde).

## Estructura del Proyecto

- `/backend`: API REST ultra rápida desarrollada en **NestJS**, **Prisma ORM** y **PostgreSQL**.
- `/frontend`: Aplicación Web SPA moderna desarrollada en **Angular 20**, **Vanilla CSS** y **RxJS / Signals**.
- `docker-compose.yml`: Orquestación lista para despliegue en un clic en **Coolify**.

## Despliegue en Producción (Coolify)

Este monorepo incluye los Dockerfiles y la configuración de `docker-compose.yml` listos para ser conectados directamente en Coolify.
